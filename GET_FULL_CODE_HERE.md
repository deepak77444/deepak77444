## 💡 Features Included

The code supports:

**Audio Control**:
- 5.1 channel volume control
- Master volume (0-100)
- Bass and treble adjustment
- Mute function

**Inputs**:
- AUX1, AUX2, AUX3
- USB (with power control)
- DVD/HDMI (via FT003)

**Display**:
- 16x2 LCD display
- Real-time volume display
- Input source indicator
- Custom welcome message

**Remote Control**:
- 41+ IR remote codes
- Power, volume, mute
- Input selection
- Channel navigation

**Hardware**:
- Arduino UNO (ATmega328P)
- PT2258/TDA7313 audio IC
- VS1838B IR receiver
- Rotary encoder
- FT003 HDMI extractor
